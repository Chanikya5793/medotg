# Contributing

Thanks for your interest in contributing!

## Ways to contribute

- Report bugs and request features via GitHub Issues
- Improve documentation
- Submit pull requests

## Getting started

1. Fork the repository
2. Create a new branch for your change:

   ```bash
   git checkout -b feature/my-change
   ```

3. Make your changes and add tests where appropriate
4. Run the project checks/tests (if available)
5. Commit with a clear message
6. Open a pull request

## Pull request guidelines

- Keep PRs focused and reasonably sized
- Describe the motivation and the approach
- Link relevant issues (e.g., `Fixes #123`)
- Add or update documentation as needed

## Code style

- Follow the existing style in the codebase
- Prefer clear, readable code over clever code

## Reporting bugs

Please use the bug report issue template and include:

- Steps to reproduce
- Expected behavior
- Actual behavior
- Environment details

## Community

This project follows the [Code of Conduct](./CODE_OF_CONDUCT.md). By participating, you agree to abide by its terms.
